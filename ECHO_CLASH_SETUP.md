# ECHO CLASH: THE ARENA REMEMBERS — Setup and Run Guide

Engine: **Godot 4.7.2 stable** (standard build, GDScript only, no .NET). Project root: `D:\devmaycry` (this repository). Verified on Windows 11, RTX 4060 Laptop GPU, D3D12 renderer.

## Open the project

1. Launch `Godot_v4.7.2-stable_win64.exe` (the editor binary).
2. In the Project Manager choose **Import**, pick `D:\devmaycry\project.godot`, then **Open**.
3. Press **F5** (Run Project). The main scene is `res://src/ui/Title.tscn`.

The project needs no third-party assets. All geometry, materials, sounds and UI are generated by code or
produced by `tools/gen_sfx.py` (already run; the WAVs are committed under `assets/sfx`).

## Play offline against bots

1. Title screen → **PLAY / OFFLINE PRACTICE**.
2. Pick mode (Corebreak or Relic Rush), map (Oracle Gardens, Tideline Exchange, Vector Foundry), team size or player count, bot fill and bot difficulty (Easy / Medium / Hard).
3. **OPEN PRACTICE LOBBY** → **START MATCH**. Bots fill the vacant seats when the match starts.

## Host a LAN room (same Wi-Fi / LAN only)

1. Title screen → **HOST LAN ROOM** → choose settings → **CREATE ROOM**.
2. The lobby shows a 6-character **room code** and the host's IP addresses. Use **COPY ROOM CODE** to copy it.
3. When the first room is hosted, Windows Firewall asks whether to allow Godot on private networks. Click **Allow**, otherwise other machines cannot reach UDP ports 24642 (game) and 24643 (room-code beacon).
4. Press **START MATCH** once everyone is in the roster. Only the host can start, change settings or add bots.

## Join a LAN room

1. Title screen → **JOIN ROOM**, type the 6-character code → **FIND AND JOIN BY CODE**. The game listens for the host's UDP beacon for 6 seconds and connects automatically.
2. If discovery fails (some hotspots and guest networks block broadcast), type the host IP shown in the host's lobby and press **JOIN BY IP**.

There is no internet matchmaking in this build. Room codes are only discoverable on the same local network.

## Two instances on one machine (for testing)

```
powershell -File tools\run_two.ps1 -Mode corebreak -Map oracle_gardens -Bots -TeamSize 2
```

Opens a host window and a client window on localhost. Press START MATCH in the host window.

## Automated checks (no editor needed)

Set `GODOT` to the console binary if it is not at the default Downloads path.

```
powershell -File tools\godot.ps1 --headless --import                         # refresh class cache after new scripts
powershell -File tools\godot.ps1 --headless --script res://tests/run_tests.gd  # 34 unit tests
powershell -File tools\net_test.ps1 -Clients 2 -Mode corebreak                 # headless host + 2 clients
powershell -File tools\screenshot.ps1 -Map tideline_exchange -Bots            # windowed run, saves build\shots\*.png
```

Headless runs accept these user arguments after `--`: `--role=host|join|code`, `--ip=`, `--port=`, `--code=`,
`--practice`, `--autostart=<sec>`, `--min_players=`, `--mode=corebreak|relic_rush`, `--map=<id>`, `--bots=true|false`,
`--team_size=`, `--ffa_size=`, `--bot_difficulty=easy|medium|hard`, `--auto=<pattern>` (scripted input),
`--log-snap`, `--quit-after-sec=`, `--screenshot-at=`, `--navprobe=`.

## Package a Windows build

Export templates for 4.7.2 must be installed (`%APPDATA%\Godot\export_templates\4.7.2.stable`). Then:

```
powershell -File tools\godot.ps1 --headless --export-release "Windows Desktop" build\EchoClash.exe
```

Run `build\EchoClash.exe` on two machines on the same Wi-Fi to test a real LAN room.
