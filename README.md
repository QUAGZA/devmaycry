# ECHO CLASH: THE ARENA REMEMBERS

First-person competitive tactical arcade built in **Godot 4.7.2** for a 24-hour hackathon.
Identity: PALIMPSEST / ARCHITECTURE OF BROKEN TIME. The arena keeps a record of the last six seconds and both
teams can bend it.

**HOT RETURN** (primary): attackers steal the Causal Core from the defenders' vault and carry it home to their
Stabilizer before its 26-second volatility fuse detonates. Two Stability Fields off the direct route each pause
the fuse for 7 seconds. Attackers get **Reverse Entropy** (once per round: drop the Core, rewind its volatility
6 seconds and freeze it while your body re-traverses your route backwards, aiming and firing freely). Defenders
get **Fast-Forward Entropy** (once per round: an 8 m / 3 s field that speeds the fuse, bullets and their own
aim). Tagged barricades restore as temporary cover along a rewinding player's path. Four original projectile
weapons with learnable recoil, humanoid player figures, three arenas with their own traversal mechanic (phase
gates, ziplines, vector slings), bots at three difficulties, LAN rooms with 6-character codes, and
**RELIC RUSH** as a free-for-all secondary mode.

## Layout

```
project.godot            Godot 4.7 project (3D, Forward+, Jolt, 1920x1080, audio bus layout)
src/autoload/            Net (session, room codes), Game (RPC hub, snapshots, projectiles), Palette, Settings, Sfx
src/player/              Player (server-simulated FPS body, rewind, weapons), TacticalRig, FPArms, HumanoidRig (legacy), BotBrain
src/rules/               HotReturnRules/Mode, RelicRules/RelicRushMode, EchoBuffer (6 s history), Corebreak (legacy)
src/weapons/             Weapons data (recoil, spread, falloff), ProjectileManager
src/match/               Match scene, MatchServer, Objectives (Core, fields, Stabilizer, FF ring), Fx
src/maps/                MapDef + MapKit toolkit, PlanRunner + Facades (execute the generated plans in plans/), OracleSanctuary / TidelineHall / FoundryLoop (final maps), OracleGardens (Developer Test Arena), legacy Tideline/Foundry, features/ (gates, ziplines, slings, ladders, TemporalProp)
src/shaders/             palimpsest_toon, ink_outline, sea, core, rewind, fastforward_ring, stability_field, portal_ring, surface, minimap_mask
src/style/               Style material library, MaterialPreview scene
src/ui/                  Title (front end), IntroSequence, MenuStage (dark real-time Core scene), MenuEntry, HUD, Minimap, UiTheme, AutoPilot (scripted input for tests)
assets/sfx/              28 procedural WAV cues (tools/gen_sfx.py) + bg_soundtrack/theplan.wav (menu music, supplied)
assets/ui/               map preview cards for the match setup screen (generated by tools/mapproto)
tests/                   run_tests.gd (78 headless unit checks), music_test.gd
tools/                   godot.ps1, net_test.ps1, map_checks.ps1, retrieve_test.ps1, bot_soak.ps1, screenshot.ps1, package.ps1, speck_check.py, gen_sfx.py, mapproto/ (map plan authoring + analysis)
build/                   EchoClash.exe (exported), logs/, shots/
```

Visual identity: ink, porcelain, signal vermilion, oxidized mint, archival cobalt, instrument brass, rendered
through an original toon shader with painted CC0 detail maps and a screen-space ink outline. Characters, animation,
weapon bodies, nature props and impact sounds are CC0 assets from Quaternius, Kenney and Poly Haven, restyled to the
palette: see [ASSET_REGISTER.md](ASSET_REGISTER.md).

Front end (startup sequence, main menu, match setup, settings): a separate dark palette - graphite `#101419` / `#1B232B`,
teal `#48E0C1` for interaction and energy, amber `#FFB454` and coral `#FF624D` for team and combat states, text `#F3F0E8` -
over a small real-time Causal Core scene (`MenuStage`). The menu music is the supplied `theplan.wav`.
